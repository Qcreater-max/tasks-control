# tasks-control 全功能管理台

一个**单文件、零依赖、开箱即用**的个人全功能管理台 —— 目标打卡、每日任务、子弹笔记、财务记账、人情往来、复盘年报，全部整合在一个网页里。

> 在线使用（数据存云端、多端同步、支持多人共用）：https://workbuddy.link/p/tRCdgEuyfIigvszEhKSRju

---

## ✨ 功能总览

### 📅 今日
- **今天要处理**：进行中的学习目标以紧凑列表呈现（名称 + 状态短句 + 迷你进度条），点击单条展开完整详情（进度、截止日、障碍与应对预案、打卡表单），支持一键全部展开/收起
- **每日任务**：任务可拆分子任务，子任务默认折叠（`子任务 2/3`），支持优先级、预估时间、开始时间
- **子弹笔记**：快速记录任务 / 笔记 / 事件 / 灵感
- **今日时间轴**：按时间线汇总当天任务、打卡与开销
- **今日开销简报**：当天收支一目了然

### 🗓️ 日历与看板
- **日历**：月视图 / 周视图切换，每天标记任务、打卡、开销三种事件点，点击日期查看当日明细
- **目标看板**：进度环、连续打卡天数、完成日期推算
- **投入图表**：近 14 天投入分钟（分目标堆叠柱状图）
- **打卡节奏**：本周打卡热力 + 本月总结

### 📈 复盘与年报
- **本期复盘**：周 / 月 / 年三种周期，保持-问题-尝试-预案四栏式复盘，一键生成报告文本（可复制到微信、邮件）
- **历史复盘**：往期复盘列表，点击载入
- **年计划进度**：年度核心目标逐级拆解追踪

### 💰 财务与人际
- **记收支**：本月支出 / 收入 / 结余统计 + 快捷记账
- **收支分析**：年度支出类别占比图 + 全部收支记录
- **购买礼物**：礼物清单（预算、实际花费、状态、想法备注）
- **人情往来**：送礼 / 收礼台账，自动计算人情净值

### 👤 我的
- **数据同步**：数据在线存储、多端同步、多人共用实时同步（他人改动自动刷新）
- **外观设置**（存云端）：背景图上传、字体族、字号缩放、卡片不透明度、毛玻璃、圆角、主题色、背景遮罩
- **数据管理**：清空示例数据 / 清空全部数据
- **手机使用**：添加到主屏幕当 App 用

## 🎨 界面设计

- **侧边栏导航**：5 大分区（今日 / 日历与看板 / 复盘与年报 / 财务与人际 / 我的），每个分区带子分支，可折叠展开；窄屏自动变为抽屉式（左缘右滑呼出）
- **分段视图**：每页顶部胶囊分段条 + 侧边栏子项联动，一次只看一块，不用翻到底
- **主题自定义**：7 项外观参数即时预览，保存后云端同步到所有设备
- **响应式**：手机（390px）到桌面全适配，移动端表单防 iOS 缩放

## 🚀 使用方式

### 方式一：在线版（推荐）
直接打开 https://workbuddy.link/p/tRCdgEuyfIigvszEhKSRju —— 数据保存在云端资料库数据表，换设备不丢，支持把链接分享给家人共同使用。

手机上：浏览器打开 → 分享 → 「添加到主屏幕」，即可像 App 一样全屏使用。

### 方式二：本地打开
本仓库的 HTML 是零依赖单文件，下载后双击即可在浏览器中运行。

> 注意：本地打开时没有云数据库环境，页面会进入**离线演示模式**（界面完整可用，数据不持久化）。需要在线存储请使用上面的在线版。

### 方式三：GitHub Pages
本仓库已包含 `index.html`，在仓库 **Settings → Pages** 中选择 `main` 分支即可免费启用静态托管。

## 🧱 技术实现

- **纯原生**：无框架、无构建、无外部依赖，单个 HTML 文件（约 130 KB）
- **数据层**：通过宿主环境注入的资料库数据库 SDK（`window.__SMART_PAGE__.database`）读写云端数据表；`db.onUpdated` 订阅数据变更实现多人实时同步（600ms 防抖 + 写入回声识别）
- **数据表结构**：9 张表 —— 学习目标 / 打卡记录 / 子弹笔记 / 每日任务 / 收支 / 礼物 / 人情往来 / 复盘 / 外观设置
- **兼容性**：ES5 语法，兼容主流移动端与桌面浏览器
